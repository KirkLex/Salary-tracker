# Финансы

Личный трекер доходов и расходов в браузере. Счета, бюджет, повторяющиеся операции, цели и отчёт за месяц. Суммы можно вести в разных валютах и смотреть в одной валюте учёта.

На сводке есть «Нить месяца»: календарь трат и два прогноза до конца месяца — если повторять выбранный день и если держать текущий темп.

У каждого человека свой аккаунт. Учёт хранится в базе Neon, сайт открывается на Vercel. Пароль в базе лежит только в виде шифра.

## Как запустить

1. Откройте адрес сайта на Vercel.
2. Нажмите «Регистрация», укажите почту и пароль от 8 символов.
3. После входа правки сами сохраняются в ваш аккаунт.
4. «Выйти» находится в шапке и в боковом меню.

Файл `index.html` с диска вход не выполняет: запросы к базе идут только с опубликованного сайта.

## Чем собран

Обычные HTML, CSS и JavaScript, без фреймворка и без сборщика.

| Что | Зачем |
| --- | --- |
| `index.html` | Страница и разметка разделов |
| `css/style.css` | Оформление, темы, вёрстка для телефона, планшета и широкого экрана |
| `js/storage.js` | Книга учёта. Копия в браузере и отправка в аккаунт |
| `js/app.js` | Операции, фильтры, отчёты, «Нить месяца», вход |
| `js/charts.js` | Графики |
| `api/` | Вход, регистрация и сохранение учёта |
| [Neon](https://neon.tech) | База Postgres: пользователи, сессии, учёт |
| [Vercel](https://vercel.com) | Сайт и серверные функции |
| [Chart.js 4.4.6](https://www.chartjs.org/) | Столбцы и кольцо, подключается с jsDelivr |
| [Fraunces](https://fonts.google.com/specimen/Fraunces) и [Outfit](https://fonts.google.com/specimen/Outfit) | Шрифты с Google Fonts |
| Node.js | Нужен только чтобы выложить проект командами `neonctl` и `vercel` |

Тема и валюта учёта по-прежнему лежат в браузере. Сами операции после входа хранятся в Neon. Копию можно скачать в разделе «Данные»: JSON для всего учёта, CSV для операций.
