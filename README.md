# Финансы

Личный трекер доходов и расходов в браузере. Счета, бюджет, повторяющиеся операции, цели и отчёт за месяц. Суммы можно вести в разных валютах и смотреть в одной валюте учёта.

На сводке есть «Нить месяца»: календарь трат и два прогноза до конца месяца — если повторять выбранный день и если держать текущий темп.

Данные остаются в браузере, на сервер ничего не отправляется. Опубликованная копия: [kirklex.github.io/Salary-tracker](https://kirklex.github.io/Salary-tracker/).

## Как запустить

Сборки нет. Нужен только браузер.

Откройте `index.html` двойным щелчком или перетащите файл в окно браузера.

Либо поднимите любую статическую раздачу из папки проекта и откройте её адрес. Например, в PowerShell:

```powershell
python -m http.server 8765
```

Затем откройте `http://127.0.0.1:8765`.

У `file://` и у `http://127.0.0.1` разные хранилища: записи, сделанные при одном способе открытия, не появятся при другом.

## Чем собран

Обычные HTML, CSS и JavaScript, без фреймворка и без сборщика.

| Что | Зачем |
| --- | --- |
| `index.html` | Страница и разметка разделов |
| `css/style.css` | Оформление, темы, вёрстка для телефона, планшета и широкого экрана |
| `js/storage.js` | Книга учёта и `localStorage` |
| `js/app.js` | Операции, фильтры, отчёты, «Нить месяца» |
| `js/charts.js` | Графики |
| [Chart.js 4.4.6](https://www.chartjs.org/) | Столбцы и кольцо, подключается с jsDelivr |
| [Fraunces](https://fonts.google.com/specimen/Fraunces) и [Outfit](https://fonts.google.com/specimen/Outfit) | Шрифты с Google Fonts |

Тема (светлая, тёмная, авто) и валюта учёта тоже лежат в `localStorage`. Копию всей книги можно скачать и вернуть в разделе «Данные»: JSON для всего учёта, CSV для операций.
